Что такое криптовалюта?

Криптовалюта - это цифровой актив, который передается между участниками сети без центрального банка. Записи о переводах хранятся в блокчейне: распределенной базе данных, которую одновременно проверяют тысячи компьютеров.

Большинство блокчейнов позволяют проверить транзакции публично, сохраняя при этом псевдонимность пользователей.

Первые шаги

Как начать безопасно

  1. 1

    Изучите риски

    Цена криптовалют может резко меняться. Используйте только те суммы, потеря которых не повлияет на ваш бюджет.

  2. 2

    Выберите кошелек

    Для небольших сумм подойдет мобильный кошелек, для долгого хранения лучше рассмотреть аппаратное устройство.

  3. 3

    Защитите доступ

    Запишите seed-фразу офлайн, включите двухфакторную аутентификацию и не переходите по подозрительным ссылкам.
